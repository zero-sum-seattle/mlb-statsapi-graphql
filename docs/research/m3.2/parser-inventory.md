`stats` is the fallback module when the response omits a group; it is not
advertised by the captured MLB statGroups endpoint. `game` uses `_type`, which
the dispatcher does not read. `team` is empty; `streak` is a placeholder.

Rows without `stat` still face the dispatcher’s nonempty `stat` precondition.
Some then require other fields and may fail validation. Imported classes are
included because the dispatcher scans all classes in a module. Exact spelling
and capitalization above are significant (including `byDateRangeAdvancedbyMonth`).
